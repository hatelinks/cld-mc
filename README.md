# Сборка Minecraft 1.21.1 (NeoForge 21.1.248)

Рабочий репозиторий сборки «Create + MineColonies + Mystical Agriculture» для ПК (Prism Launcher) и Android (Amethyst).

- `CLAUDE.md` — карта проекта: версии, где что лежит, как собирать и тестировать.
- `HANDOFF.md` — история сборки и подробные грабли.
- `docs/` — карта кода каждого нашего мода (`docs/<мод>.md`): какие файлы за что отвечают, настройки, грабли.
- `pack/` — конфиги экземпляра Prism и `MODS.md` (что стоит в игре, с SHA-1). `pack/OPTIMIZATION.md` — замеры и ускорения клиента. Полная сборка с jar — архив в Releases.

## Свои моды и данные

| Папка | Что это | Версия |

| `pregen/` | Предпросмотр мира (cld_pregen): прегенерация с живой картой на экране создания мира. | 1.3.2 |
| `structures/` | Структуры без наложений (cld_structures): структуры разных модов не появляются друг в друге. | 1.0.0 |
| `gdn/` | «Горы до небес»: рельеф jjtm как отдельные типы мира. | 1.0.0 |
| `jjtm/` | Неофициальный порт датапака JJThunder To The Max (1.20.1) на 1.21.1 для личного использования (лицензия оригинала: All Rights Reserved). Архив, источник данных для gdn. | 0.3.3 |
| `menu/` | Главное меню сборки (cld_menu). | 1.0.1 |
| `earlywindow/` | Свой экран загрузки (cld_earlywindow, провайдер `cldwindow`). | 1.0.0 |
| `perf/` | Ускорения клиента (cld_perf): ровный ограничитель кадров. | 0.1.0 |
| `autotest/` | Служебный cld_autotest: сам заходит в мир и меряет FPS, CPU, память. В игру не ставить. | 0.1.3 |

| `quest_builder/` | Генератор квестов FTB Quests: `python3 -I quest_builder/make.py` → `out/ftbquests_config.zip`. | — |
| `qa/` | Проверки перед выдачей: статическая проверка jar и датапаков, смоук-тест сервера, разбор логов, бенчмарк генератора. | — |
| `tools/` | `fetch_libs.sh` собирает библиотеки NeoForge для сборки модов без Prism, `publish_prerelease.sh` выкладывает jar пререлизом. | — |
| `releases/` | Jar пререлизов: при пуше workflow создаёт тег и prerelease на GitHub. | — |

В планах: панель тестирования в стиле старого клиента Nodus поверх Baritone 1.11.3 (окна по клавише и из меню Esc, управление командами и настройками Baritone, инструменты проверки мира в одиночной игре).

## Сборка и выпуск

Java-моды собираются без Gradle: `LIBS=<папка с jar NeoForge 21.1.248> <мод>/build.sh` → `<мод>/dist/`. Версия мода задаётся в его `build.sh`. Каждая новая версия выходит на GitHub только пререлизом: `tools/publish_prerelease.sh <мод>-<версия> путь/к.jar`. Подробнее в `CLAUDE.md`.

## Настройки Prism (Mac)
Java Azul Zulu 21.0.13, аргументы Java пустые (обычный G1), память 2048–6144 МБ. ZGC и 8 ГБ давали крэши.

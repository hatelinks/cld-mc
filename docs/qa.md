# qa: проверки и замеры (и служебный мод cld_qabench)

Карта кода. Читать вместо разбора исходников; кто меняет инструменты, обновляет эту страницу в своём PR. Порядок приёмки и таблица инструментов: `qa/README.md`.

## Файлы
| Файл | За что отвечает | Сеть |
|---|---|---|
| `check_mods.py <mods> [--datapacks ...] [--android] [--server]` | Статическая проверка набора jar: дубли modId, зависимости и версии (как FML), несовместимости, jarjar, mixin-конфиги, датапаки (pack_format 48, имена папок 1.21), нативки, риски Android, клиентские моды на сервере. | нет |
| `tests/selftest.py` | Проверка самой check_mods на заведомо сломанных модах и датапаках. | нет |
| `server.sh <mods> [датапаки]` | Смоук-тест выделенного сервера NeoForge 21.1.248: установка, запуск, `datapack list`, `reload`, прогрузка 160x160, `stop`, отчёт. | maven.neoforged.net, mojang |
| `log_report.py <latest.log> [crash-reports]` | Разбор лога: время запуска, ошибки по модам, краши; безвредный шум (IDAS, CSA) отдельно. | нет |
| `jfr_top.py` | Сводка JFR по потокам, методам и пакетам. Вход: `jfr print --stack-depth 64 --events jdk.ExecutionSample rec.jfr`. | нет |
| `bench/tcw.sh [сид] [чанков] [потоков]` | Генератор tcw без игры (`TcwChunkBench.java` + пакет `tcw/gen`), контрольная сумма рельефа; `JFR=1` профиль. | нет |
| `bench/server_pregen.sh <прогон> <tcw.jar> ["-Dключи"]` | Настоящий сервер (`BASE`, по умолчанию `~/qa-server/base`; полная сборка `BASE=~/qa-server/full`), сид 12345, разогрев 21x21 у -200 -200, замер `SIZE` (32, то есть 65x65 чанков) у 2048 5968. Итог `QABENCH done` (сек, чанки/с, MSPT, TPS, heap) и `<прогон>/b.jfr`. | нет, если сервер установлен |
| `bench/cmpregion.py <мир A> <мир B> <cx> <cz> <r>` | Сравнить блоки и биомы двух миров по region-файлам. | нет |

## cld_qabench (`qa/bench/cldbench/`)
Служебный мод для `server_pregen.sh`, в игру не ставить. Собирается `qa/bench/cldbench/build.sh` -> `dist/cld_qabench-1.0.0.jar` (по умолчанию `LIBS=../../../../libs`, лучше задать явно).

| Файл | За что отвечает |
|---|---|
| `QaBench` | Команда `/qabench <cx> <cz> <r> [в работе]`: прегенерация квадрата и строка `QABENCH done`. |
| `FeatureTimes` + `mixin/PlacedFeatureMixin` | Время и число вызовов каждой placed_feature, строки `QAFEAT` в конце прогона. |
| `mixin/AquiferDebugMixin` | Отладка: где водоносный слой просит обновить жидкость (`-Dqabench.aquiferLog=N`). |

## Грабли
- Два прогона одной версии дают разные руды, капельник, скалк, песок у берегов (порядок генерации соседних чанков): сверять только «версия против той же версии», рельеф проверять `bench/tcw.sh`.
- Машина в облаке в разное время даёт разную скорость: сравнивать только прогоны подряд.
- Клиент с рендером и Android в облаке не проверить: для них чек-лист «что посмотреть в игре» и разбор присланных логов.

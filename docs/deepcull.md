# cld_deepcull: глубина по требованию (эксперимент exwip)

Карта кода. Кто меняет мод, обновляет эту страницу в своём PR.

- modId `cld_deepcull`, папка `deepcull/`, версия **0.1.0** (`VERSION` в `deepcull/build.sh`). Только клиент. Эксперимент: jar и тег с суффиксом `-exwip` (`cld_deepcull-exwip-0.1.0`), в main без согласия владельца не мёржить.
- Идея владельца: пока игрок на поверхности, уровень пещер в чанках не строится и не рисуется, а когда спускается ниже по Y, подгружается. Генерацию мира не трогает.

## Что уже делает Sodium (0.8.13) сам
- Обход видимости (`OcclusionCuller.processQueue`) идёт от камеры по секциям и проходит дальше только через открытые грани. У непостроенной секции `visibilityData = 0`, то есть закрыта со всех сторон.
- Секция попадает в очередь на сборку меша, только когда обход до неё дошёл (`SectionCollector.visit`, `getPendingUpdate`).
- Поэтому пещеры, закрытые камнем со всех сторон, Sodium и так не строит и не рисует. Ванила 1.21.1 (`SectionOcclusionGraph`) делает то же.
- Чего Sodium не отсекает: всё, до чего обход дотекает через входы в пещеры, овраги, сеноты, залы tcw с выходом наверх, шахты. Такие сети пещер строятся и рисуются целиком, хотя с поверхности их не видно. Мод режет именно это.

## Как работает
| Файл | За что отвечает |
|---|---|
| `DeepCull` | `hide(x, y, z)` для секции: прячет, если камера не ниже поверхности своего чанка и верх секции ниже самой низкой поверхности (`WORLD_SURFACE`) в чанке и 8 соседях минус `margin`. Секции на `keep` ниже камеры не трогает. Поверхности чанков в кэше, сброс раз в 5 с и при загрузке чанка. При смене режима просит граф пересчитаться. |
| `mixin/sodium/OcclusionCullerMixin` | Sodium: `OcclusionCuller.isSectionVisible` HEAD, спрятанная секция не видна: не в очереди на сборку, не рисуется, обход через неё не идёт. Конфиг `cld_deepcull.sodium.mixins.json` необязательный. |
| `mixin/SectionOcclusionGraphMixin` | Ванила (Android без Sodium): `getRelativeFrom` RETURN, спрятанный сосед как за краем мира. |
| `SodiumHook` | `SodiumWorldRenderer.scheduleTerrainUpdate()`, отдельно, чтобы без Sodium не грузить его классы. |
| `DeepCullMod`, `DeepConfig` | Клавиша F8 (вкл/выкл), строка в F3 `cld_deepcull: ...` (сколько проверок в секунду кончились отсечкой), конфиг. |

## Настройки
`config/cld_deepcull-client.toml`: `enabled` (true), `margin` (16 блоков), `keep` (2 секции).

## Сборка
```sh
LIBS=/mnt/project-files/libs deepcull/build.sh   # deepcull/dist/cld_deepcull-exwip-neoforge-1.21.1-0.1.0.jar
```
Sodium нужен только для компиляции: внутренний jar из `META-INF/jarjar` лежит в `/mnt/project-files/libs-extra/` (`SODIUM=` чтобы указать другой).

## Грабли
- Уже построенные глубокие секции при включении отсечки только перестают рисоваться, память под меши не освобождается.
- В овраг или сенот, который начинается в соседнем дальше чем через один чанк, сверху может быть видна пустота вместо дальней части пещеры. Лечится `margin` побольше.
- Замер FPS и времени сборки мешей до и после делает владелец в игре: F8 переключает на лету, в F3 строка Sodium `C:` (видимые и все секции) и наша строка.

# cld_perf: Ускорения клиента сборки

Карта кода. Читать вместо разбора исходников; кто меняет мод, обновляет эту страницу в своём PR.

- modId `cld_perf`, папка `perf/`, версия **0.1.0** (`VERSION` в `perf/build.sh`). Только клиент (`dist = CLIENT`).
- Место для мелких клиентских правок, каждая только против тормоза, видного в замере (Spark, JFR, cld_autotest). Сейчас одна правка: ровный ограничитель кадров.
- Пререлиз: `releases/cld_perf-0.1.0/`.

## Сборка
```sh
LIBS=/mnt/project-files/libs perf/build.sh   # perf/dist/cld_perf-neoforge-1.21.1-0.1.0.jar
```

## Файлы
| Файл | За что отвечает |
|---|---|
| `PerfMod` | Пустой класс мода. |
| `mixin/RenderSystemMixin` | Заменяет `RenderSystem.limitDisplayFPS` (HEAD, cancel). Следующий кадр отсчитывается от расписания, а не от момента пробуждения: на Mac `glfwWaitEventsTimeout` просыпается поздно, при лимите 90 выходило 79 кадров. Если сильно отстали или лимит сменился, расписание начинается заново. |

## Настройки
Нет.

## Грабли
- Сравнивать FPS в замерах только без лимита или с cld_perf: ванильный лимит на Mac сам срезает 12-15% кадров.
- Новые правки добавлять сюда же отдельными миксинами, с замером до и после в `pack/OPTIMIZATION.md`.

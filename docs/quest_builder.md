# quest_builder: генератор квестов FTB Quests

Карта кода. Читать вместо разбора исходников; кто меняет генератор, обновляет эту страницу в своём PR.

- Папка `quest_builder/`, Python без зависимостей. Не мод, а генератор конфига FTB Quests: 36 глав, около 1300 квестов, русский язык.
- Группы глав: без группы «Путь выжившего», «Эра механизмов», «Хозяйство и путешествия», «Мистическое земледелие», «Жизнь колонии».

## Сборка
```sh
python3 -I quest_builder/make.py   # out/ftbquests_config.zip и out/checklist.md (папка out/ в корне репозитория)
```
`make.py`: `data_base/` копируется в `data/` -> по порядку выполняются `specs/*.py` (каждый `run(book)` добавляет квесты) -> `book.save()` -> `build.py` собирает SNBT и zip.

## Файлы
| Файл | За что отвечает |
|---|---|
| `make.py` | Полная пересборка (см. выше), печатает, сколько квестов добавил каждый spec. |
| `build.py` | `data/*.json` -> `out/ftbquests/quests/*.snbt`, `lang/ru_ru.snbt`, `out/checklist.md`, `out/ftbquests_config.zip`. ID квестов сохраняются (поле `id`), новые считаются хешем главы и ключа (`hid`), старший бит всегда 0. Предметы сверяются со списками из jar (`jars/*.json`, `jars_new/_valid.json`); неизвестные становятся квестами-галочками (`CHECK_TITLES`). `trusted.json` список id, которым верим без проверки. Файл `USE_FILTER` включает FTB Filter System (в сборке его нет). |
| `data_base/*.json` | Ручные главы-основы (19 штук). |
| `data/*.json` | Результат specs, перезаписывается при каждой сборке (руками не править). |
| `specs/10..95_*.py` | Главы по темам: 10 аддоны Create, 20 прочие аддоны, 30 авиация, 40 MineColonies, 50 второстепенные моды, 60 активности, 70 моды без предметов, 90 награды, 95 группы глав. |
| `tools/gen.py` | Класс `Book`: `chapter`, `add` (квест на предметы с автоописанием и автозависимостями), `adv` (достижение), `custom`, `auto_deps`, `save`. |
| `tools/lex.py` | Справочник из `jars_new/`: русские названия, подсказки, рецепты, теги, модели. |
| `tools/layout.py` | Автораскладка главы: колонки по длине цепочки, барицентр, сетка листьев. |
| `tools/fam.py` | Семейства предметов (цвета, породы дерева и камня) для «любой вариант». |
| `tools/snbt.py`, `tools/import_zip.py` | Парсер SNBT и импорт готового zip квестов обратно в json. |
| `tools/gen_ma_gear.py`, `tools/patch_rewards.py`, `tools/vanilla_ru.py`, `tools/preview.py` | Генерация глав снаряжения Mystical Agriculture, пул наград, русские названия ванили, картинка раскладки (путь в `preview.py` старый, `/home/claude/out`). |
| `jars/`, `jars_new/` | Выгрузка из jar сборки: id предметов по модам, `*.lang.json`, `_valid.json` (у кого есть модель), `_recipes.json`, `_tags.json`, `_adv.json`, `_models.json`, `_world.json`. |

## Правила (из `HANDOFF.md` §2)
- Все задачи на предметы `consume_items: false`, во всех главах `progression_mode: "flexible"`.
- ID предмета должен иметь модель (`_valid.json`), иначе квест не покажется.
- Lang-строки без переносов, иначе все названия «Безымянный». ID квестов без старшего бита, иначе «Unnamed».
- Вариантные квесты засчитывают только базовый вариант (FTB Filter System нет).
- После обновления модов (особенно авиации) пересобрать `jars_new/` из новых jar и квесты: ID могли поменяться.
- `checklist.md`: квесты-галочки вместо несуществующих предметов и описания «по общим знаниям», которые надо проверить в игре.

# cld_pregen: Предпросмотр мира

Карта кода. Читать вместо разбора исходников; кто меняет мод, обновляет эту страницу в своём PR.

- modId `cld_pregen`, папка `pregen/`, версия **1.3.2** (`VERSION` в `pregen/build.sh`, можно `VERSION=1.3.3 pregen/build.sh`).
- Кнопка «Предпросмотр» на вкладке «Мир» экрана создания мира (над «Тип мира»). Создаёт мир, замораживает его и прегенерирует чанки по спирали, рисуя живую карту. Можно сменить сид и пересоздать, оставить мир или удалить.
- Клиент и сервер (`side=BOTH`): серверная часть (`PregenTask`) работает во встроенном сервере.

## Сборка
```sh
LIBS=/mnt/project-files/libs pregen/build.sh   # pregen/dist/cld_pregen-neoforge-1.21.1-1.3.2.jar
```

## Файлы
| Файл | За что отвечает |
|---|---|
| `PregenMod` | Подписка на `ServerTickEvent.Post` (тик задачи) и `ServerStoppingEvent` (стоп), на клиенте `ClientHooks.init()`. |
| `server/PregenTask` | Обход по спирали (квадрат или круг), не больше `maxInFlight` чанков одновременно, `msPerTick` мс на тик. Свой тикет `cld_pregen`, неблокирующий `getChunkFutureMainThread`. Колбэки через очередь сервера (`later`). |
| `server/ChunkSample` | Снимок чанка для карты: MapColor верхнего блока, глубина воды, высота, биомы 4x4, старты структур. |
| `server/MapData` | Общая карта снимков (сервер пишет, экран читает), очередь свежих. |
| `mixin/ServerChunkCacheInvoker` | Invoker к `ServerChunkCache.getChunkFutureMainThread`. Единственный миксин. |
| `client/ClientHooks` | Кнопка «Предпросмотр» (ставится каждый кадр над кнопкой «Тип мира», потому что вкладки пересобирают виджеты без Init), запуск сеанса после загрузки мира, запрет меню паузы, дальность прорисовки 2 на время карты. |
| `client/PreviewSession` | Один сеанс: замораживает сервер (`tickRateManager().setFrozen`), `keep()` оставляет мир, `discard(seed)` удаляет мир и по желанию сразу создаёт с новым сидом. |
| `client/PreviewScreen` | Экран: слева панель (сид, случайный, применить сид, радиус 8-500, форма, приоритет 12/48/128 чанков в работе, мс на тик 1-50, старт/стоп, вид, слои прогресс/слизни/структуры, скриншот, GC), справа карта; колесо масштаб, перетаскивание сдвиг. |
| `client/MapView` | Карта тайлами 32x32 чанка, отдельная текстура на тайл; масштаб 1/2/4 блока на пиксель по радиусу (`bppFor`); режимы вида блоки, биомы, высоты; картинка для скриншота. |
| `client/Palettes` | Цвета биомов и высот. |
| `client/DhCompat` | Distant Horizons через отражение: на время карты генерация и рендер DH выключены, 1 поток. В мирах не gdn/tcw дальняя генерация DH выключена. Значения ставятся через API и не пишутся в конфиг. |
| `assets/cld_pregen/lang/*.json` | Все подписи экрана (ключи `cld_pregen.*`). |

## Настройки
Файла конфига нет, всё на экране предпросмотра.

## Грабли
- В замороженном мире временный тикет `UNKNOWN` от `getChunkFuture` сам не снимается: снимаем вручную сразу после запроса, иначе утечка памяти и остановка генерации (1.1.2).
- Публичный `getChunkFuture` в потоке сервера ждёт чанк и вкладывает ожидания: тик не кончается, мир не грузится. Поэтому invoker к `getChunkFutureMainThread` (1.3.1).
- Перед `mc.disconnect()` вызывать `mc.level.disconnect()`, иначе вечное ожидание выключения сервера.
- `removed()` экрана закрывает карту только после конца сеанса: экран может временно смениться окном подтверждения.
- DH сейчас из сборки убран (заменён cld_far), `DhCompat` просто ничего не делает без него.

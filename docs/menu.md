# cld_menu: Главное меню сборки

Карта кода. Читать вместо разбора исходников; кто меняет мод, обновляет эту страницу в своём PR.

- modId `cld_menu`, папка `menu/`, версия **1.5.0** (`VERSION` в `menu/build.sh`). Только клиент.
- Живой пиксельный пейзаж вместо кубической панорамы (во всех меню, где она была), логотип «TelipailoCraft» шрифтом Minecraft, без кнопок Realms и «Моды», без строк версий внизу слева.
- С 1.1.0 пейзаж рисуется в память (`scene/`, без Minecraft) и одной текстурой выводится на экран. Погода выбирается при каждом запуске (7 видов, зимой снег 4 запуска из 5), время суток и фаза луны по часам компьютера, время года по календарю.
- С 1.2.0 два ближних слоя собраны из настоящих блоков Minecraft (текстуры текущего ресурс-пака): трава, земля, камень, вода и лёд, дуб, берёза, ель, весной вишня, трава и цветы; зимой всё заметено. Солнце, луна и облака из текстур игры (`sun.png`, `moon_phases.png`, `clouds.png`).
- С 1.3.0 у меню звуки: фон природы синтезом (ветер, вьюга, дождь, птицы днём, сверчки ночью), гром игры рядом (сразу, громко) и вдалеке (тихо, ниже, с задержкой), капли дождя игры. Ползунок «Звуки меню» в настройках звука, музыка в непогоду тише.
- С 1.4.0 экран «Наши моды» (общий экран настроек сборки ведёт этот мод): кнопка в правом верхнем углу настроек и меню паузы, слева разделы, справа настройки с кнопкой «Сброс».
- С 1.5.0 пейзаж считается в отдельном потоке, слои сдвигаются за мышью, днём пролетают птицы, летними ночами светлячки, осенью листопад, весной лепестки. Замер запуска игры в `logs/cld_startup.log` и в разделе «Скорость запуска». Свои надписи у логотипа.

## Сборка
```sh
LIBS=/mnt/project-files/libs menu/build.sh   # menu/dist/cld_menu-neoforge-1.21.1-1.5.0.jar
```

## Файлы
| Файл | За что отвечает |
|---|---|
| `MenuMod` | Подписывает `TitleButtons.onInit` на `ScreenEvent.Init.Post`. |
| `Landscape` | Связка сцены с игрой: размер растра 1/270 высоты окна, кадр считается в потоке `cld_menu landscape` в один из двух растров (первый кадр сразу в потоке игры), готовый загружается в `DynamicTexture` (`cld_menu:landscape`) и выводится одним `blit`. Не чаще `fps`, в неактивном окне 5 раз в секунду. Сдвиг за мышью (`Scene.parallax`). Выбор погоды и сезона, подпись внизу слева при F9. |
| `scene/Scene` | Вся отрисовка: небо полосами с узором Байера, звёзды и падающие звёзды, квадратные солнце и луна с фазой, радуга, облака рядами, 4 слоя гор (снежные шапки, ели и лиственные деревья по сезону, цветы), туман полосами, дождь и снег в два слоя, брызги, метель, молнии рядом и вдалеке, виньетка. |
| `scene/Weather`, `WeatherKind` | Вид погоды (`pick` по сезону), силы облаков, дождя, снега, ветра, тумана во времени, удары молний (`Strike`: место, расстояние, вспышка; `listener` для звуков). |
| `scene/Sky`, `Season` | Солнце по часам (длина дня по сезону, широта около 55), луна, заря, фаза луны; сезон по месяцу (зима это декабрь, январь, февраль). |
| `scene/Blocks` | Текстуры блоков: оттенок травы и листвы, свет и дымка кадра (кэш на слой), `draw` блока любого размера с прозрачностью, `drawTop` для слоя снега. Слои из блоков рисует `Scene.blockLayer`, деревья `Scene.tree`. |
| `scene/Tex` | Текстура ARGB и `Tex.Source`: в игре `Landscape.texture` (ресурс-паки, перечитываются после перезагрузки ресурсов), в превью из `client-*-extra.jar`. Без текстур ближние слои рисуются силуэтами. |
| `MenuSounds` | Каждый тик: включает фон (`AmbientSound`, поток `Stream` 22050 Гц моно из `Ambient`) пока пейзаж на экране и мира нет, капли `WEATHER_RAIN_ABOVE`, гром по `Weather.Strike` (`playDelayed`), множитель музыки. Категория `MASTER`, громкость умножается на `sounds`. |
| `scene/Ambient` | Синтез фона: ветер (шум через фильтры, порывы), свист вьюги, шум и капли дождя, три вида птиц, три сверчка. `target(weather, sky)` задаёт громкость слоёв, слои меняются плавно. Поля `volatile`: пишет поток игры, читает поток звука. |
| `SoundSlider` | Ползунок «Звуки меню» в конце `SoundOptionsScreen` (через `ScreenEvent.Init.Post`), сохраняет `sounds` в конфиг. |
| `mixin/SoundEngineMixin` | `calculateVolume(SoundInstance)` RETURN: музыка умножается на `MenuSounds.musicFactor()`. |
| `assets/cld_menu/sounds.json` | Событие `cld_menu:menu.ambient` ссылается на ванильный `ambient/weather/rain1` (stream), чтобы прошла проверка файла; сам звук берётся из `getStream`. |
| `OurModsScreen` | Экран «Наши моды». Разделы: «Главное меню» (погода, время года, время суток, звуки, музыка в грозу, частота пейзажа; применяется сразу через `Landscape.applyConfig`), по разделу на каждый наш мод из `ModList` (modId `cld_*`, `tcw`, `sable_android`: версия, описание, кнопка «Открыть настройки мода», если мод дал `IConfigScreenFactory`, как cld_far и cld_bombs), «Датапаки сборки» (в мире показывает, включены ли `pack_fixes`, `colony_guard`). Последний раздел запоминается. При узком экране (guiScale 6) колонки сжимаются. |
| `MenuMod` | Кроме событий: `IConfigScreenFactory` для cld_menu (открывает «Наши моды»), кнопка «Наши моды» в `OptionsScreen` и `PauseScreen` через `ScreenEvent.Init.Post`, F9 в главном меню. |
| `StartupTimer` | Время от старта JVM до конструктора, `FMLClientSetupEvent`, `FMLLoadCompleteEvent` и первого главного меню; строка в `logs/cld_startup.log`. |
| `Splashes`, `mixin/SplashManagerMixin` | В половине запусков своя жёлтая надпись по-русски, праздничные ванильные не трогает. |
| `scene/MenuConfig` | `config/cld_menu.properties`: `weather`, `season`, `time`, `fps`. |
| `scene/Raster`, `Col`, `Noise` | Картинка int[] RGB, цвета, хеш и шум. |
| `Logo` | Название из lang-ключа `cld_menu.title` (`assets/cld_menu/lang/en_us.json`): объёмные изумрудные бока, обводка, масштаб по ширине экрана. |
| `TitleButtons` | Убирает кнопки с ключами `menu.online` (Realms) и `fml.menu.mods`, сдвигает остальные вверх на освободившиеся ряды. |
| `mixin/PanoramaRendererMixin` | `PanoramaRenderer.render` HEAD, cancel: рисует `Landscape`. |
| `mixin/LogoRendererMixin` | `LogoRenderer.renderLogo` HEAD, cancel: рисует `Logo`. |
| `mixin/TitleScreenMixin` | `@Redirect` на `BrandingControl.forEachLine` в `render` (без строк версий); после `init` обнуляет `realmsNotificationsScreen` (значки Realms). |

## Настройки
В игре: Настройки или Esc, кнопка «Наши моды» справа вверху, раздел «Главное меню». Тот же файл:
`config/cld_menu.properties` (создаётся сам): `weather` (auto, clear, rain, thunder, snow, fog, blizzard, rainbow), `season` (auto, winter, spring, summer, autumn), `time` (auto или 21:30), `fps` (60), `sounds` (громкость звуков меню 0..1, 0.7), `musicInStorm` (доля громкости музыки в грозу, дождь и метель, 0.45). Название меняется в lang-файле.
В главном меню F9 следующая погода, Shift+F9 время года, Ctrl+F9 плюс два часа (для проверки, не сохраняется).

## Превью вне игры
Пакет `scene` не зависит от Minecraft: `LIBS=/mnt/project-files/libs menu/tools/shots.sh папка` (текстуры из `client-*-extra.jar` в LIBS) собирает `tools/MenuPreview` и рисует сетки погоды в PNG (и пишет время кадра). Он же пишет WAV звуков меню (`tools/AmbientWav`, без грома и капель игры). Один вызов: `java -cp out MenuPreview out.png 480 270 thunder,snow winter 22:30 30`.

## Грабли
- Сцена и `Weather.update` работают в фоновом потоке: текстуры (`Scene.textures`), смена размера и `parallax` меняются только когда кадр не считается; удары молний идут в очередь `MenuSounds.STRIKES`, звук запускается в тике игры.
- Свой звук без файла: `SoundInstance.getStream` (патч NeoForge) отдаёт свой `AudioStream`, но событие в `sounds.json` должно указывать на существующий ogg со `stream: true`, иначе звук отбрасывается при загрузке. Буфер потока около секунды, поэтому смена погоды в звуке слышна с задержкой до нескольких секунд.
- В `build.sh` jar NeoForge перечисляется отдельным `ls` раньше `client-*-srg.jar` (исправлено в 1.2.0).
- В `NativeImage` порядок байт ABGR, растр хранит RGB: переставлять при загрузке (`Landscape.upload`).
- 1.0.1: не падать при возврате в меню из настроек.
- Кнопки ищутся по ключу перевода; если мод поменяет подпись кнопки, она не уберётся.

# cld_far — Дальний рельеф

Лёгкая дальняя прорисовка для миров TelipailoCraft. Рисует только рельеф: поверхность, воду, снег и скалы, цвет по биому. Деревьев и построек нет.

Как работает:
- Высоты и цвета считаются генератором tcw прямо по сиду, в фоновых потоках с низким приоритетом. Чанки не грузятся и не генерируются.
- Мир разбит на тайлы 32×32 клетки: у игрока шаг `step` блоков, дальше каждый уровень вдвое грубее. Пока тайл не посчитан, рисуется его грубый родитель, поэтому дыр нет.
- Готовый тайл один раз загружается в видеокарту и больше не перестраивается. За кадр загружается не больше 4 тайлов.
- Рисуется после неба своей проекцией, потом обычные чанки поверх. Где игра уже нарисовала чанк, дальний рельеф отбрасывается в шейдере по маске чанков (с Sodium по готовым секциям и с учётом того, что Sodium не рисует выше и ниже прорисовки по высоте). Туман игры сдвигается к краю дальнего рельефа.
- Высокие скалы рядом, которые игра не рисует по высоте, и всё в поле зрения подзорной трубы достраиваются блочными тайлами.
- Каменные столбы генератора (карст, доломит, Патагония) рисуются отдельно по формуле tcw, одиночные пики в режиме блоков сужаются ступенями.
- Под водой, в лаве, порошковом снеге, при слепоте и темноте дальний рельеф не рисуется.
- Сид генератора (не сид мира) передаёт сервер при входе, поэтому мод нужен и на сервере. В одиночной игре это происходит само.

Установка: `cld_far-*.jar` в `mods/` рядом с `tcw-*.jar`. Distant Horizons убрать.

Настройки: кнопка ⛰ в «Настройках» (справа от строки «Поле зрения») и в «Настройках графики» (правый верхний угол), клавиша **F7** или `config/cld_far-client.toml`.

Настройки разбиты на разделы, у каждой есть описание (наведи мышь).

| Раздел | Параметр | По умолчанию (ПК / Android) | Что даёт |
|---|---|---|---|
| Основное | enabled | вкл / выкл | рисовать или нет (клавишу-переключатель можно назначить в «Управлении») |
| | distance | 8192 / 2048 | дальность, блоков |
| | fog | 0.55 | с какой доли дальности начинается туман |
| Качество | step | 8 | шаг сетки у игрока; меньше, подробнее, дольше считать |
| | mountains | 2 / 1 | во сколько раз мельче сетка в горах (1-3) |
| | detail | 2.5 | как далеко держится мелкая сетка |
| Вид | pixel | 2 | 0, гладкие склоны, 1, плоские грани, 2, ступеньки-блоки |
| | smooth | 0.15 | сглаживание вдали: 0, острые пики как есть, 1, мягко |
| | pillars | вкл | каменные столбы tcw круглыми и на своём месте |
| | peaks | вкл | одиночные вершины иглой, а не коробкой (при pixel 2) |
| | trees | вкл | леса вдали: кроны бугром над землёй |
| Вода | clearWater | вкл / выкл | прозрачная дальняя вода с дном (нужна для волн и бликов) |
| | waves | вкл | рябь на воде |
| | sunGlint | 0.6 | блики солнца |
| | waterReflect | 0.5 | отражение неба под острым углом |
| | ice | вкл | замёрзшая вода льдом |
| | shore | вкл | пена у берега, бирюзовое мелководье |
| | rivers | вкл | узкие реки не рвутся вдали |
| Вид | blockSides | вкл | бока блоков: под травой земля, под снегом камень |
| | mesaBands | вкл | слои терракоты на обрывах пустошей |
| Свет и цвет | sunShade | 0.35 | освещение от солнца по времени суток (ночью от луны) |
| | valleyShade | 0.35 | затенение впадин |
| | colorNoise | 0.5 | пестрота цвета, как текстуры блоков |
| | brightness | 1.0 | яркость |
| | saturation | 1.0 | насыщенность |
| | haze | 0.3 | дымка к горизонту |
| | skyHaze | вкл | дымка цвета неба |
| | sunset | вкл | тёплый свет на рассвете и закате |
| | weather | вкл | в дождь и грозу темнее, туман ближе |
| Небо и воздух | cloudShadows | 0.3 | тени облаков |
| | valleyMist | 0.4 | туман в низинах, утром гуще |
| | curvature | 0.25 | дальний край уходит за горизонт |
| Блоки и труба | nearBlocks | вкл / выкл | высокие скалы рядом за прорисовкой по высоте достраиваются блоками |
| | spyglass | вкл / выкл | в подзорную трубу всё в поле зрения блочное |
| | spyglassRange | 1024 | до какой дальности блочный рельеф в трубе |
| | blockSize | 1 | размер блока блочного рельефа: 1 или 2 |
| Производительность | threads | 0 (авто) / 1 | фоновые потоки расчёта |
| | uploadsPerFrame | 4 | тайлов в видеокарту за кадр |
| | adaptiveUploads | вкл | при просадке кадров по одному тайлу |
| | pauseInMenu | вкл | на паузе расчёт ждёт |
| | lookAhead | вкл | сначала то, что впереди |
| | maxVramMb | 1024 / 256 | лимит видеопамяти |
| | sampleCacheMb | 256 / 64 | кэш рельефа в памяти |
| | diskCache | вкл / выкл | кэш рельефа на диске (`cld_far_cache/`) |
| | diskCacheMb | 1024 | лимит кэша на диске для мира |

Строки статистики (тайлы, очередь, видеопамять, кэш) видны справа на экране F3.

С 0.6.0 настройки лежат в разделах `config/cld_far-client.toml`, старые значения из 0.5.x не переносятся (встают по умолчанию).

Проверка вне игры (без libs, только исходники tcw):
```sh
javac -d /tmp/far tcw/src/main/java/dev/cld/tcw/gen/*.java far/src/main/java/dev/cld/far/gen/*.java far/tools/FarPreview.java
java -cp /tmp/far FarPreview 42 7000 +60 7000 30 8192 8 2.5 180 out.png 4
```
Печатает, сколько тайлов на каждом уровне, и за сколько они считаются. Рисует кадр программным растеризатором.

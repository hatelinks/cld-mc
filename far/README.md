# cld_far — Дальний рельеф

Лёгкая дальняя прорисовка для миров TelipailoCraft. Рисует только рельеф: поверхность, воду, снег и скалы, цвет по биому. Деревьев и построек нет.

Как работает:
- Высоты и цвета считаются генератором tcw прямо по сиду, в фоновых потоках с низким приоритетом. Чанки не грузятся и не генерируются.
- Мир разбит на тайлы 32×32 клетки: у игрока шаг `step` блоков, дальше каждый уровень вдвое грубее. Пока тайл не посчитан, рисуется его грубый родитель, поэтому дыр нет.
- Готовый тайл один раз загружается в видеокарту и больше не перестраивается. За кадр загружается не больше 4 тайлов.
- Рисуется после неба своей проекцией, потом обычные чанки поверх. Внутри обычной прорисовки дальний рельеф вырезается в шейдере, туман игры сдвигается к краю дальнего рельефа.
- Сид генератора (не сид мира) передаёт сервер при входе, поэтому мод нужен и на сервере. В одиночной игре это происходит само.

Установка: `cld_far-*.jar` в `mods/` рядом с `tcw-*.jar`. Distant Horizons убрать.

Настройки: клавиша **F7** или `config/cld_far-client.toml`.

| Параметр | По умолчанию (ПК / Android) | Что даёт |
|---|---|---|
| enabled | вкл / выкл | рисовать или нет |
| distance | 8192 / 2048 | дальность, блоков |
| step | 8 | шаг сетки у игрока; меньше — подробнее, дольше считать |
| mountains | 2 / 1 | во сколько раз мельче сетка в горах (1–3); 2 — примерно в 2,5 раза больше вершин в горном мире |
| detail | 2.5 | как далеко держится мелкая сетка |
| threads | 2 / 1 | фоновые потоки расчёта; меньше — меньше нагрев |
| fog | 0.55 | с какой доли дальности начинается туман |

Проверка вне игры (без libs, только исходники tcw):
```sh
javac -d /tmp/far tcw/src/main/java/dev/cld/tcw/gen/*.java far/src/main/java/dev/cld/far/gen/*.java far/tools/FarPreview.java
java -cp /tmp/far FarPreview 42 7000 +60 7000 30 8192 8 2.5 180 out.png 4
```
Печатает, сколько тайлов на каждом уровне, и за сколько они считаются. Рисует кадр программным растеризатором.
